# 转场、探索骨架与海报首帧（2026-11-27）

本次落实用户选定的三项 UI 优化，沿用现有主题、圆角、间距和动效设置。

## 页面转场

`lib/ui/app_motion.dart` 使用有状态组件持有 `CurvedAnimation` 和缩放动画。路由逐帧重建时复用同一个对象；父动画变化时解除旧监听，组件销毁时释放曲线。中途返回沿用当前曲线方向，不会因重新选择退出曲线而跳变。既有预测式返回包装与路由时长保持原有行为。

`test/app_page_transition_test.dart` 检查逐帧重建时监听数稳定、正反向切换时画面连续、动画父对象替换和卸载时监听清理，以及实际 Navigator 的快速进入/返回和减少动画模式。

## 探索页骨架

`DramaSkeletonGrid` 与真实网格共用列数、间距、2:3 海报比例和按字号计算的高度。推荐页额外使用 `ExploreHeroSkeleton`，与真实推荐大卡片共享布局计算，避免结果返回后整排海报被大卡片向下挤动。占位使用主题色静态绘制，不创建持续运行的闪烁或扫光动画；占位卡片不参与焦点和朗读，只保留“正在加载”状态提示。

骨架仅用于没有内容的加载态。已有内容刷新继续展示原列表；空列表、失败提示、下拉刷新和电视分类栏保留原有交互。

`test/explore_skeleton_test.dart` 覆盖手机、平板、桌面和电视布局，以及手机两倍字号、大卡片加载前后矩形一致、刷新保留内容与滚动位置、骨架网格的尺寸和静态绘制。既有分类横滑、顶栏折叠、邻页预取和电视焦点测试一并回归。

## 海报首帧

`lib/ui/widgets/cover_image.dart` 在图片文件可读但解码尚未完成时继续显示同尺寸占位。新下载图片首次异步解码完成后，以 `AppMotion.state`（当前 200ms）淡入，结束后撤下占位与透明度包装。

磁盘缓存命中、同步解码缓存命中、低分辨率背景、快速滚动建议延迟加载、减少动画或隐藏页面场景不启动淡入。切换减少动画或隐藏状态时结束正在进行的淡入。普通重建、窗口调整解码尺寸以及动图后续帧不重复播放入场。已有缓存清理、身份切换撤图、失败重试和图片实例复用逻辑仍由原组件负责。

`test/cover_frame_transition_test.dart` 通过可控的图片流延迟真实解码首帧，验证占位不会过早消失、淡入中间状态、尺寸稳定、缓存和滚动策略，以及中途减少动画。既有封面权限隔离、清理、重试、解码尺寸和解码器退出回归一并通过。

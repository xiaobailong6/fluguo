# Windows 全屏恢复验收

使用本次代码构建的 Windows 应用和本地测试视频；记录应用版本、Windows 版本、显示器布局、DPI 和任务栏自动隐藏设置。`python -B scripts/test_windows_fullscreen.py -v` 是结构检查，不能代替下列运行验收。

| 操作 | 通过条件 |
| --- | --- |
| 普通窗口移至副屏，记录大小/位置，进入全屏再退出 | 全屏占满该显示器（不只占工作区）；任务栏不遮挡。退出后回到原屏普通窗口、原大小与位置。 |
| 将窗口最大化，进入全屏，进入画中画，退出画中画，再退出全屏 | 画中画置顶；返回时仍在原屏全屏；退出全屏后仍最大化。再按“还原”能回到原普通窗口。 |
| 分别关闭、开启用户置顶，重复上述路径；切换到其他应用再返回 | 退出画中画后恢复用户选择的置顶状态；不能以永久置顶掩盖任务栏问题。 |
| 在不同缩放比例显示器间移动；快速重复进入/退出全屏 | 不跨屏跳动、不遗留黑窗、不覆盖普通窗口位置记录。 |

本次环境：结构检查 7 项通过；未找到本次构建的应用可执行文件或 MSVC 工具链，因此上述窗口行为均为 **待实机验收**。

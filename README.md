# FlGuo

Flutter 多端独立短剧 / 影视应用，手机、平板、电脑和电视分别适配。

- **标准版**（`FlGuo`）：包含红果、饭果、爽果。
- **全站源版**（`FlGuo-all-sources`）：含全部站源，可在设置里逐个开关。

## 使用

| 功能 | 说明 |
| --- | --- |
| 导航 | 默认剧场 / 短剧 / 直播 / 追剧 / 我的，可在设置中调整菜单顺序并保存。手机用底栏，平板和电脑用侧栏（可收起），电视用顶部 Tab；宽屏的子页面在侧栏右侧打开 |
| 界面模式 | 自动识别、电视、手机、平板、窗口（只有电脑提供）；手动选定后不随窗口宽度切换。电视模式强制横屏，手机模式锁定竖屏 |
| 主题 | 跟随系统取色（Android 12+ 跟随壁纸，Windows 和 macOS 跟随强调色）或 6 个预设色板；浅色 / 深色 / 跟随系统 |
| 短剧 | 点击左上角站源名称展开玻璃下拉切换站源；分类 Tab 依次为推荐 / 全部 / 各榜单 / 各题材，榜单封面标出名次。第一个 Tab 顶部大卡片显示最近看过或推荐的剧。滑到底自动加载，下拉或「刷新」重新拉取当前分类。设置 → 播放可关闭「显示剧集信息过渡页」，卡片及搜索结果直接进入播放，显式「详情」入口仍保留 |
| 剧场 | 首集预览流接近队尾自动追加，约70%兴趣匹配、30%随机探索，优先新内容，有限片库耗尽后循环合规候选；网络失败可重试。进入自动隐藏手机底栏，点击中央唤出；上下滑切换推荐。底部低矮液态玻璃「看全集」横条贴底，点击进入完整播放页；首集结束也自动进入全集，多集从第二集继续。返回保留原推荐与预览位置，不立即再次跳转 |
| 搜索 | 只搜当前站源，保留最近搜索；红果有输入联想 |
| 详情 | 封面模糊作底，显示集数、完结状态、分类、播放量、标签和简介；选集每组 30 集，落在续播那一集，看过的集变浅，VIP 集有标记。打开时后台预缓冲续播集 |
| 播放 · 电脑 | 左边视频、右边选集栏，可宽屏、全屏；悬停弹出清晰度、倍速、音量；支持空格、Enter、方向键、M 等快捷键 |
| 播放 · 手机 | 横屏和竖屏视频均使用同一沉浸播放 UI，按比例居中，上下空白填黑；从短剧卡片和剧场进入保持一致。上下翻页切集，左右滑快进快退，右上角依次是画中画、弹幕开关、追剧、播放设置（三点菜单，屏幕正中央弹出），长按左侧 2 倍速，可锁定 |
| 播放 · 平板 | 横着拿同电脑，竖着拿同手机，全屏期间锁定横屏 |
| 播放 · 电视 | 播控浮在画面上，隐藏时左右键快退 / 快进 10 秒；返回键依次关闭选项、收起播控、退出；换集回详情页选 |
| 直播 | 两版均包含哔哩哔哩、斗鱼、虎牙、抖音；全站源版另保留秀果（仅映客）。独立一级/二级分区、四点完整分区选择；多线路时可独立切换线路与画质，全屏右下角以深色胶囊凸显两项菜单。抖音支持真实分类及分页，分区无图片时按需使用对应分区当前直播封面；匿名搜索可能受平台风控限制。双击播放/暂停，全屏菜单单击唤出、闲置收起。收藏按平台区分并支持批量管理 |
| 播放通用 | 下一集提前缓冲，翻页和连播直接接上；倍速、清晰度和弹幕开关会记住。红果在线播放有弹幕，本地播放不加载 |
| 追剧 | 只分追 / 不追。有新集的剧排在「有更新」并标出更新集数；可搜索、按站源筛选、多选取消。后台每 30 分钟检查一批未完结的追剧 |
| 观看记录 | 短剧和直播记录仅保留最近 30 天，启动、恢复前台和持续运行时按日清理过期数据，不影响追剧收藏与下载文件。按今天 / 昨天 / 更早分段；可搜索、按来源筛选、多选删除，「清空」只清当前列出的记录 |
| 我的 | 用户卡、最近观看、下载概况和设置入口；底栏 / 侧栏图标显示正在下载的集数 |
| 下载 | 详情页「下载选集」或播放页选集栏多选（点选、拖选、全选）。下载页分「下载中」「已下载」，可单集或全部暂停 / 继续 / 重试；已下载按剧显示，可播放、删除、补齐缺集。电视端不提供下载 |
| 设置 | 外观、播放、下载、站源、代理、用户、关于、诊断 8 组，改动立即保存；没有权限的项置灰并注明原因 |
| 用户 | 多用户独立保存追剧、记录和搜索，轻点即切换；管理员可添加、编辑、删除用户，设置能访问的站源和是否允许下载 |
| 备份 | 导出 / 恢复用户、追剧、观看记录和偏好设置（含主题色），已下载视频不受影响；旧版备份仍可导入。本地配置损坏时启动页可从备份恢复 |
| 本地保存 | 用户与观看记录、追剧、直播收藏等保存在应用支持目录的 `store/` 下，按用户和类别分文件，首次自动迁移旧快照；临时文件、上一版与事务日志用于恢复。Windows/macOS 记住普通窗口位置尺寸，原显示器移除时回到主屏居中 |

每集下载完自动转成普通 mp4（红果先解密，m3u8 合成一个文件），保存为「下载目录 / 剧名 / 第 N 集.mp4」，可以直接拷出使用。旧版下载的分集保持原样，旧版合并出的文件不再列出。

画中画、画质增强、排序与筛选、剧集长按菜单、红果多季切换暂不提供。

## 安装

在 [Releases](../../releases) 下载对应平台的包。两版应用均显示为 **FlGuo**：标准版文件名为 `FlGuo-<版本>-<平台/架构>`，全站源版为 `FlGuo-all-sources-<版本>-<平台/架构>`。更名不改变应用标识、本地数据目录、备份格式或更新接口的 edition 标识，兼容旧版数据。

| 平台 | 安装包                                                                                    |
| --- |----------------------------------------------------------------------------------------|
| Android 7.0+ | arm64-v8a / armeabi-v7a / x86_64 三种 APK，按设备架构选择（大多数手机选 arm64-v8a）；同一签名可覆盖升级，旧证书版本需卸载重装 |
| Windows 10/11 x64 | 完整 ZIP，解压后运行 `FlGuo.exe` / `FlGuo-all-sources.exe`，保留所有 DLL 与 `data` 目录 |
| iOS 15.1+ | 未签名 IPA，需自行签名或用 iloader 等工具侧载                                                          |
| macOS 12+ | 通用 dmg（Apple 芯片与 Intel），打开后拖入「应用程序」；未经公证，首次打开前执行 `xattr -dr com.apple.quarantine /Applications/FlGuo.app`（全站源版为 `FlGuo-all-sources.app`） |

安装提示 `INSTALL_FAILED_NO_MATCHING_ABIS` 表示 APK 与设备架构不匹配，请换对应架构的安装包。

## 检查更新

接收端是 Cloudflare Worker（[`worker/`](worker)）的 `GET /v1/latest`，只返回最新版本号，不接收任何上报数据；编译期没设置 `UPDATE_SERVER_URL` 时应用不会发出请求。

应用不收集匿名使用统计，也没有对应的设置开关。
